# Development instructions

GBrain Code is a repository cartographer, not a coding agent or answer generator.

- Keep its public surface limited to repository status/refresh, context mapping,
  symbol inspection, and diff auditing.
- Treat every graph edge as navigation evidence, never proof of runtime behavior.
- Keep exact citations and snapshot freshness in every consequential result.
- Do not add model consultation, autonomous editing, chat memory, or agent loops.
- Retrieval must remain selective, bounded, and honest about unresolved edges.
- Tests and direct repository inspection remain the source of truth.
